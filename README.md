# Research on AI reliability

I'm a student interested in AI and in how we know when a model can be trusted.

## Featured: WaterSense AI

Can a model estimate dissolved oxygen in rivers at monitoring stations it has never seen? I tested this on 151,031 measurements from 840 stations in Northern Ireland, and I report the failures as well as the gains.

→ [WaterSense AI](https://github.com/tzlh888/WaterSense-AI)
